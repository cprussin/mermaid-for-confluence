# Offline Mermaid Diagrams for Confluence

Render [Mermaid](https://mermaid.js.org/) diagrams (flowcharts, sequence, class, state, ER, Gantt, pie) inside Confluence Cloud pages.

## Usage

1. Edit a page and type `/mermaid`.
2. Insert **Mermaid Diagrams**, pick a template or paste Mermaid text; the preview updates as you type.
3. Publish. Hover a diagram to export it as SVG or PNG.

Diagrams render entirely inside Confluence. The app makes no external calls and stores nothing outside your site (it runs on Atlassian).
